## 二之二、封面照片来源与命名

- 照片取自公开图库：**TheMealDB**（有明确菜名的实拍图，优先）与 **loremflickr**（按关键词检索的 Flickr 实拍图，兜底）。
- 文件名统一为 `dish_<数据库id>.jpg`，URL 为 `/profile/upload/seed/dish_<id>.jpg`，
  与数据库 `food_info.image` 一一对应；100 张照片**互不重复**。
- 用户头像为 `avatar_<账号>.jpg`（真人照片），共 12 张，同样不重复。
- ⚠️ 本机网络策略拦截了大部分图片站（Wikimedia、foodish、pexels/pixabay 均超时或 403），
  因此照片是**按食材/菜系语义匹配**的最接近菜品，而非每道菜的原版照片。

## 二之三、未上传封面时的自动封面

用户发布美食若没有上传封面，后端会以「**美食名称 + 分类名称**」自动生成一张封面
（渐变底 + 菜名 + 分类名，按分类配色），实现见 `zzyl-serve` 的 `util/CoverUtils.java`。
生成的文件位于 `{ruoyi.profile}/upload/cover/`，URL 形如 `/profile/upload/cover/cover_xxx.jpg`。

## 四、封面图与头像

图片**无法联网下载**（本机网络策略拦截了图片站），因此由 `SeedGen` 用 Java2D 本地绘制：
按分类配色的渐变封面 + 菜名 + 分类名；头像为昵称首字 + 稳定配色。

⚠️ **路径约定（重要，容易踩坑）**

若依的资源映射规则是：

```
URL  /profile/X   ->   文件 {ruoyi.profile}/X
```

当前 `ruoyi.profile = ./uploadPath`（相对应用运行目录），所以：

| 文件位置 | 对应 URL |
| --- | --- |
| `uploadPath/upload/seed/dish_xxxx.jpg` | `/profile/upload/seed/dish_xxxx.jpg` |
| `uploadPath/upload/2026/09/15/xxx.png` | `/profile/upload/2026/09/15/xxx.png` |

> 注意：**不要再套一层 `profile` 目录**。把图片放到 `uploadPath/profile/upload/...`
> 会导致 `/profile/upload/...` 返回 404（本项目中曾因此排查过一次）。

上传接口 `/common/upload` 落的物理路径也是 `uploadPath/upload/yyyy/MM/dd/`。

## 六、后端编译与同步脚本（`bin/build-serve.ps1`）

改完 `zzyl-serve` 的 Java 代码后，用这个脚本编译并同步到 `target/classes`，
运行中的应用（IDEA + devtools）会自动热重启：

```powershell
powershell -File zzyl\bin\build-serve.ps1
```

脚本做的事：组装依赖 classpath → `javac -encoding UTF-8` 编译 → 复制 class 与 mapper → **逐文件校验**。

> 踩坑记录（很重要）：
> 1. `robocopy` 在文件被运行中的 JVM 占用时会返回 1~7 并**静默跳过**，
>    曾导致 `AppFoodController.class` 缺失、`/food/app/**` 全部 404。
>    脚本已改为 `Copy-Item -Force` + 逐项校验，缺文件会直接报错。
> 2. `Get-ChildItem -Recurse -Filter` 在本目录下会漏文件，脚本统一用 `-Recurse -File` + `Where-Object`。
> 3. 该脚本**必须保持纯 ASCII**：PowerShell 5.1 按 GBK 读 `.ps1`，中文串会被截断导致语法错误。

## 七、重新生成演示数据

改菜谱清单后重新生成（生成器读 `DISHES` / `CATEGORIES` / `USERS`）：

```bash
javac -encoding UTF-8 -d out SeedGen.java     # 必须带 -encoding UTF-8，否则中文字面量乱码
java -cp out SeedGen                          # 重新生成图片与 sql/food_seed_rich.sql
```

> 注意：`javac` 必须加 `-encoding UTF-8`；源文件不要带 BOM。
> 图片目录为 `zzyl/uploadPath/upload/seed`（相对仓库根目录执行）。
